## 📁 Sheet Structure

- **Dashboard** → Executive summary with main KPIs
- **Sales_Data** → Complete dataset (1,500 rows × 10 columns)
- **PT Trend** → Monthly sales trend analysis
- **T region** → Sales by geographic region
- **Sales by product category** → Revenue breakdown by product type
- **Rating by category** → Customer satisfaction by category
- **Detail1** → Detailed transaction listing
- **Product category by sales** → Alternative category view

## 🚀 How to Use This Dashboard

1. **Open the Excel file** with Excel 2016 or later
2. **Review the Dashboard sheet** for executive overview
3. **Explore the Sales_Data sheet** for complete transaction details
4. **Analyze trends** using PT Trend sheet
5. **Compare regions** using T region sheet
6. **Create custom pivot tables** for deeper analysis

### Quick Tips
- Filter by Region for geographic analysis
- Sort by Sales_Amount to identify top transactions
- Analyze Customer_Segment to understand purchasing behavior
- Review Customer_Rating to identify quality issues
- Track Shipping_Status for operational efficiency
- Group by Date for trend analysis

## 📋 Data Dictionary

| Field | Type | Description |
|-------|------|-------------|
| **Transaction_ID** | Text | Unique transaction identifier |
| **Date** | Date | Transaction date |
| **Product_Category** | Text | Product category (Beauty, Books, Clothing, Electronics, etc.) |
| **Region** | Text | Geographic region (North America, Europe, Asia Pacific, Latin America) |
| **Customer_Segment** | Text | Customer type (Premium, Standard, Budget) |
| **Payment_Method** | Text | Payment method (Credit Card, PayPal, Crypto, Bank Transfer) |
| **Shipping_Status** | Text | Delivery status (Processing, Pending, Returned, Delivered) |
| **Sales_Amount** | Currency | Transaction amount in dollars |
| **Quantity** | Number | Items purchased |
| **Customer_Rating** | Decimal | Customer satisfaction rating (1-5 stars) |
